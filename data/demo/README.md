# Демо-документы закупок

Здесь лежат документы для демонстрации жюри и ручной проверки: проекты контрактов, ТЗ,
протоколы, сметы в .pdf, .docx, .xlsx.

> **Только синтетические данные.** Репозиторий публичный (AGENTS.md, правило 2).
> ФИО, паспорта, СНИЛС, телефоны и адреса генерируются (Faker, `ru_RU`) или придумываются.
> Реальные документы с ПДн физлиц сюда класть нельзя.

## Ожидаемые находки

Рядом лежит `answers.yaml` — что система должна найти в каждом документе. По нему проверяем
демо перед защитой:

```yaml
- file: contract_orgtech.docx
  purpose: publication
  overall: red
  entities: {PERSON: 2, PHONE: 1, SNILS: 1}
  violations: [PD_IN_PUBLICATION, TRADE_SECRET_WITHOUT_MARK]
```
