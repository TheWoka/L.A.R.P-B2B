# Тексты законов для RAG

Задача **T-005**, исполнитель — **Алина**. Индексируются в T-014 (`backend/app/services/rag/index.py`).

## Формат

- Один закон — один файл в UTF-8: `152-fz.md`, `98-fz.md`, `187-fz.md`, `gdpr.md`.
- Первая строка — заголовок закона: `# Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных»`.
- Каждая статья — заголовок второго уровня строго в формате:

```markdown
## Статья 7. Конфиденциальность персональных данных

Операторы и иные лица, получившие доступ к персональным данным, обязаны ...
```

- Части и пункты статьи — обычным текстом внутри раздела, без своих заголовков `##`.
- Источник — официальная публикация (pravo.gov.ru / consultant.ru); в конце файла строка `Источник: <URL>, редакция от <дата>`.

Так индексатор режет файл по `## Статья N.`, и ссылка в нарушении (`LawRef.article = "ст. 7"`) однозначно находит текст статьи.
