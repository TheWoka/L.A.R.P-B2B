# grif-cls — классификатор фрагментов: коммерческая тайна / особые категории ПДн

- Базовая модель: `cointegrated/rubert-tiny2` (29 млн параметров, лицензия MIT).
- Задача: фрагмент (предложение) → NONE / TRADE_SECRET / SPECIAL_CATEGORY. Вход — замаскированный текст ([PERSON_1] …), как в конвейере.
- Формат: ONNX; эмбеддинги int8 (шкала на 26 чисел), веса MatMul fp16, вычисления fp32; CPU через onnxruntime, без ключа и GPU.
- Обучение (T-036a): дистилляция — облачная LLM сгенерировала и разметила синтетические фрагменты (v1: 6136 шт., v2: 6350 шт.; всего после дедупликации 12463); реальных документов и ПДн в данных нет.
- Валидация (10% синтетики): macro-F1 0.9737, эпоха 3.
- Пороги (выбраны на eval/dev, максимум F1 при precision ≥ 0.75): TRADE_SECRET 0.35, SPECIAL_CATEGORY 0.6.

## ONNX

- Размер model.onnx: 34.19 МБ (fp32 — 111.47 МБ).
- Совпадение с PyTorch на 200 фрагментах: max |Δp| fp32 0.0, int8 0.00675; совпадение argmax 1.0.
- CPU (onnxruntime): 0.348 с на 100 фрагментов, 2.771 с на 1000.

## Ограничения

- Обучен на синтетике: реальные документы длиннее, грязнее и разнообразнее.
- Сущность — весь фрагмент, а эталон — «показатель + значение»: пересечение ≥ 50% эталона засчитывается, но фрагмент с двумя фактами закроет только один эталон.
- Не ищет ПДн, финансовые показатели и реквизиты — это делают regex, NER и словари.
