# Генератор синтетического корпуса

Задача **T-011**. Генерирует документы закупок с известной разметкой для измерения качества
детекции (критерии приёмки: ≥ 90% ПДн, ≥ 85% коммерческой тайны).

## Что делает

1. Берёт шаблоны документов (проект контракта, ТЗ, протокол, смета).
2. Подставляет синтетические значения через Faker (`ru_RU`): ФИО, паспорт, СНИЛС и ИНН
   с правильными контрольными суммами, телефоны, email, адреса, счета, суммы, фразы
   о себестоимости и наценке.
3. Сохраняет документ (.docx / .xlsx / .pdf) и рядом JSON-разметку: список сущностей
   `{type, category, start, end}` в формате `Entity` из `docs/contracts.md`.
4. Часть документов — с «ловушками»: ИНН юрлица (не ПДн), номера договоров, похожие на СНИЛС.

Результат — в `eval/corpus/` (не коммитится, генерируется заново с фиксированным seed).
