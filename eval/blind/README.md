# Слепой корпус T-017c

Составитель: Codex по заданию Алины; дата составления: 23.10.2026.
Все 12 документов и все приведённые сведения придуманы специально для проверки.
Имена, контакты, адреса, медицинские и иные личные сведения не описывают реальных людей.
Организации и хозяйственные операции вымышлены; банк — АО «Банк Пример»,
БИК — 049999999, домены — example.ru и example.org. Цифровые идентификаторы
сгенерированы как синтетические примеры и не получены из реестров.

Набор слепой: при составлении не открывались код детектора
`backend/app/services/detection/*`, словарь `data/rules/dictionaries.yaml`
и исходный корпус `eval/seed/*`. Из файлов с описанием проекта прочитаны
только `AGENTS.md` и `eval/README.md`.

**Детектор под этот набор не настраивать.** Разметка подготовлена до первого
запуска оценки. После оценки не исправлять пропуски и ложные срабатывания
изменениями текста, эталонов или кода; допускается исправить только ошибку
синтаксиса разметки, если проверка завершилась с кодом 2.

## Состав и границы

Документы `01_*.txt` — `12_*.txt`: заявка, анкета, договор с ИП, письмо,
служебная записка, калькуляция, протокол, справка, лист допуска, заявление
о возмещении, лист переговоров и акт передачи. Формат — `[[TYPE:значение]]`,
без вложенных и многострочных сущностей; правила границ — из `eval/README.md`.

Личные контакты, адреса и счета размечены с указанием владельца в контексте.
В специальных категориях выделено само значение либо фраза о конкретном
человеке. Судимость и профсоюз включены по условию T-017c. Коммерческие условия
и технологические приёмы приведены с содержанием, включая разговорные формулировки.
В перечнях клиентов названы только вымышленные организации, вложенных PERSON нет.
FINANCIAL охватывает финансовые показатели и счета организаций; НМЦК, цену
и обеспечение контракта, налоговые ставки и служебные идентификаторы не размечаем.
Общие телефоны и ящики организаций, паспорт изделия и медицинские закупки
без сведений о людях оставлены без разметки.

## Проверка

Из корня репозитория в PowerShell, по одной команде:

```powershell
docker-compose build api
docker-compose run --rm --no-deps -v "${PWD}/eval:/eval" api python /eval/run_eval.py --corpus /eval/blind --out /eval/results/blind
```

Если Compose не может вывести имя проекта из кириллического имени папки,
перед командами можно задать `$env:COMPOSE_PROJECT_NAME = 'b2b'` для текущей сессии.

Результаты сохраняются отдельно в `eval/results/blind`, не заменяют основные
метрики страницы «Качество» и не включаются в коммит. Таблица оценки передаётся
в чат без исправлений. Этот README не содержит отчёта о работе детектора.
